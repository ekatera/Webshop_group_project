# Petpaws

Petpaws is a simple online pet shop web app built with React and TypeScript. It lets users browse products, search for items, view details, add products to the cart, and complete a checkout flow.

## Features

- Product listing page
- Search and filtering
- Product details view
- Shopping cart and order summary
- Checkout form
- Order confirmation page
- About page

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- JSON Server
- CSS styling

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the mock backend:
   ```bash
   npm run server
   ```
3. Start the app:
   ```bash
   npm run dev
   ```
4. Open the app in your browser at:
   ```bash
   http://localhost:5173
   ```

## Scripts

- `npm run dev` - start the Vite app
- `npm run build` - build for production
- `npm run server` - run the local JSON server
- `npm run test` - run tests
- `npm run lint` - check code quality

## Project Goal

This project is a small e-commerce demo that shows how a shop app can be built with React, routing, forms, and a local mock API.
